# Лапа — сайт ветклиники для портфолио

Вымышленная тёплая ветклиника. Выбран вариант дизайна 1 «Тёплый» (прототипы всех трёх — в `designs/`).

Next.js 16 (App Router) + TypeScript + Tailwind 4, статический экспорт без бэкенда.

## Команды

```bash
npm install
npm run dev      # разработка: http://localhost:3000
npm run build    # статическая сборка в папку out/
```

Публикация — GitHub Actions (`.github/workflows/pages.yml`) собирает сайт с подпапкой `/vet`
и выкладывает на GitHub Pages при каждом пуше в `main`.

## Где что

- `src/app/page.tsx` — страница: первый экран, услуги, почему мы, врачи, отзывы, вопросы, запись, контакты.
- `src/lib/data.ts` — тексты, цены (BYN), врачи, отзывы, телефон и адрес.
- `src/components/Pets.tsx` — нарисованные пёс и кот: следят глазами за курсором, моргают, виляют хвостом.
- `src/components/Booking.tsx` — запись: выбор питомца, телефон +375 с автоформатом. Демо, данные никуда не уходят.
